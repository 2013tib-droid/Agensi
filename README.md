# agensi

Gudang skill UI/UX untuk Claude Code, dikemas sebagai **plugin marketplace**.

```
/plugin marketplace add 2013tib-droid/agensi
/plugin install taste-skill@agensi
```

- **[PENGINGAT.md](PENGINGAT.md)**: daftar plugin, cara pakai di proyek lain, cara menambah/update skill.
- **[CLAUDE.md](CLAUDE.md)**: panduan kapan memakai skill mana.
- Setiap folder `plugins/*` menyimpan `LICENSE` dan `SOURCE.md` dari repo asalnya.
